# EDA on Retail Sales Data

## Objective
Performed exploratory data analysis on a retail sales dataset to uncover patterns, 
customer behavior trends, and actionable business insights.

## Tech Stack
Python, pandas, matplotlib, seaborn, Jupyter Notebook

## Dataset
Sample Superstore dataset (sourced from Kaggle)

## Key Steps
- Data loading and inspection (shape, dtypes, null check)
- Descriptive statistics
- Monthly sales trend analysis
- Top 10 best-selling products
- Revenue by category and sub-category
- Regional sales comparison
- Correlation heatmap
